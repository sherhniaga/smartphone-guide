# СмартГід — навчальний SEO-проєкт

Статичний сайт: HTML5, CSS3, vanilla JS. Без збірки й залежностей.

## Запуск у VS Code
1. File → Open Folder → оберіть саме папку `smartgid` (вона має бути коренем робочої області).
2. Встановіть розширення **Live Server**, ПКМ на `index.html` → *Open with Live Server*.
   Або в терміналі: `python3 -m http.server 8000` і відкрийте http://localhost:8000/
3. Не відкривайте `index.html` подвійним кліком: шляхи `/assets/...` працюють лише від кореня сервера.

## Перед публікацією
- Замінити `https://example.com` на реальний домен у всіх файлах (пошук по `example.com` має давати 0 збігів).
- Додати контактну адресу на `/pro-proiekt/`, звірити всі «демонстраційні дані».
- Додати `favicon.ico`/`apple-touch-icon.png` за потреби.
